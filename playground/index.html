Words you can use
say "Hi"shows text in the console
name = ask "Name?"asks a question and keeps the answer
x = 5stores a value in a name
if x > 3 … else … enddoes something only sometimes
repeat 3 times … enddoes something again and again
while x < 10 … endrepeats as long as something is true
for each i from 1 to 10 … endcounts
for each f in list … endgoes through a list
function greet(who) … endmakes your own command
[1, 2, 3] list[1]a list; the first item is number 1
random(1, 6) length(x)a dice roll; how long something is
canvas 400, 300sets the picture size
background "skyblue"paints the whole picture
color "red"picks the color for what comes next
circle x, y, radiusdraws a circle
rect x, y, width, heightdraws a rectangle
line x1, y1, x2, y2draws a line (thickness 5 makes it fat)
triangle x1, y1, x2, y2, x3, y3draws a triangle
text "Hi", x, ywrites on the picture
clear wait 0.1wipe the drawing; pause
cat = sprite "🐱", 200, 300a figure for games; it stays on the picture
cat.x += 5 cat.size = 80move it, make it bigger (also .y .angle .hidden)
repeat forever … endthe game loop: runs 60 times per second
if key "left"is a key held down? (arrows, space, letters)
if cat touches stardo two sprites overlap?
if star tappedwas the sprite tapped or clicked?
touch_x touch_y touchingwhere the finger or mouse is
show "Score: {score}"text on top of the game; {…} fills in a value
stopends the program (game over)
